# Cybersecurity Portfolio

This repository hosts my professional portfolio and project documentation for\
all courses in the Master's in Cybersecurity at the University of Malaya.

* **Live Portfolio Website:** [https://RoseWiz.github.io/Cybersecurity-Portfolio/](https://RoseWiz.github.io/Cybersecurity-Portfolio/)
* **Projects Directory:** [`/projects`](./projects/)

## Repository Structure

```text
cybersecurity-portfolio/
├── README.md          # Repository overview and link to the live GitHub Pages site
├── index.md           # Home page of the live portfolio (all seven required sections)
├── _config.yml        # Jekyll configuration and theme settings for GitHub Pages
├── .gitignore         # Excludes secrets, local build files, and large binaries
├── projects/
│   ├── virtual-lab-setup/
│   │   ├── README.md  # Project 1 write-up
│   │   └── evidence/  # Sanitised screenshots, diagrams, and configuration exports
│   └── network-reconnaissance-rool/
│       ├── README.md  # Project 2 write-up
│       └── evidence/  # Sanitised scan logs, diagrams, and screenshots
└── assets/
    └── images/        # Site images and diagrams
```
